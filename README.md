# 💻 Zainab's Portfolio — the actual one, not a draft

No formalities here. You know the deal.

This is Zainab Faraz's portfolio site — final-year SWE student, professional shipper of things, currently open to Summer 2026 internships. Built to look like the inside of her own dev environment instead of another templated "hire me" page.

## 🧠 The whole idea

Nav tabs = file names. Experience = a git log. Skills = a code panel. Contact = a terminal you run like a script. If you're going to build a portfolio for a developer, it should look like something a developer actually lives in — not a stock cream-and-serif landing page that every third portfolio on the internet has right now.

## ✨ What's in it

- 🖥️ A terminal-style hero (`whoami`, status, blinking cursor, the works)
- 📜 An experience section styled as an actual git commit log — hashes, `HEAD → main`, the graph line
- 📦 Projects laid out like GitHub repo cards, language dots and all
- 🗂️ Skills rendered as a syntax-highlighted `stack.jsonc` file
- 📱 Fully responsive, keyboard-friendly, respects reduced motion
- 🎨 A palette that isn't the same three AI-generated defaults everyone's tired of

## 🛠️ Built with

- HTML
- CSS (a lot of it, all handwritten, no framework)
- A bit of JS for the reveal animations, mobile nav, and the terminal typing effect
